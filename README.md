# Mothership app

TK

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Deploy to GitHub Pages

Every push to `main` is built and deployed by GitHub Actions
(`.github/workflows/deploy.yml`). To redeploy without a new commit, run the
"Deploy to GitHub Pages" workflow manually from the Actions tab.
